# NOVACAB — Frontière métier / administration

## Raccordements administratifs
- mission exceptionnelle créée -> demande à l'administration
- résiliation -> demande à l'administration
- entrée de mission -> signal administratif
- sortie de mission -> signal administratif
- document/lettre administrative -> demande à l'administration
- blocage administratif -> demande à l'administration
- suivi honoraires/encaissements -> indicateurs de pilotage

## Hors administration
TVA, FEC, saisie comptable, production comptable, paie et traitement fiscal restent dans l'espace métier.
