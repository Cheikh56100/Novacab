# NOVACAB

Cockpit principal de pilotage cabinet.

## Applications connectées
- NOVACAB Insight
- NOVACAB Tax
- NOVACAB Mobilité
- OFX Bridge

## Développement
```bash
npm install
npm run dev
```

## Build Netlify
- Build command: `npm run build`
- Publish directory: `dist`

## Variables Vite
Configurer dans Netlify : `VITE_INSIGHT_URL`, `VITE_TAX_URL`, `VITE_MOBILITE_URL`.
