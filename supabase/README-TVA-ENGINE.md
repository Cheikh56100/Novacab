# Moteur TVA — référence

La version SQL de référence du moteur TVA est :

- `tva-engine-v9-autonome.sql`

Les anciennes versions V2/V4/V5/V6/V8 ont été retirées du dépôt de livraison afin d'éviter toute ambiguïté sur la version à déployer. Leur historique doit désormais être suivi par Git.

Avant toute évolution du moteur, créer un commit dédié et tester les règles TVA concernées.
