# NOVACAB V2.2.1 — Liaison métier ↔ Administration

Cette évolution applique la règle : une information métier est saisie une seule fois et les vues de pilotage la dérivent.

## Principales liaisons
- Bilan terminé dans le dossier → Tableau des bilans → À réclamer selon la périodicité du dossier.
- Tâches du dossier → indicateurs de production Admin.
- Affectations et informations dossier → lecture directe dans les tableaux Admin.
- Les factures ne sont pas générées dans NOVACAB : le pilotage indique uniquement à réclamer / payé / reste à payer pour le système de facturation externe.
- Les imports Excel des référentiels restent disponibles ; l'étape suivante est la prévisualisation/validation avant import.
- Le mois administratif reste le contexte d'archivage ; les données métier affichées sont celles de la source dossier.
